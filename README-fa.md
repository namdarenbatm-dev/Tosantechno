# اپ PWA توسن تکنو
1. کل پوشه را روی یک میزبان **HTTPS** آپلود کنید (Vercel، Netlify، Nginx و ...). فایل شروع: index.html
2. اندروید (Chrome): نوار «نصب» ظاهر می‌شود یا منو ← Install app.
3. آیفون (Safari): دکمه اشتراک‌گذاری ← Add to Home Screen.
4. آیکون برنامه همان لوگوی توسن تکنو است (icons/). برای انتشار نسخه جدید، نام V در sw.js را عوض کنید.
نکته: داده‌ها نمایشی‌اند؛ اتصال به بک‌اند و درگاه واقعی در فاز ۱ انجام می‌شود.
